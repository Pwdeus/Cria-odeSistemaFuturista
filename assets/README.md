# Lume 2075 – Casa inteligente

Painel de controle de uma casa inteligente do futuro: iluminação, temperatura, portas e eletrodomésticos.

## Integrantes
- Nome 1
- Nome 2

## Funcionalidades
- Iluminação por cômodo (brilho, cor e cenas) com uma orbe de luz interativa
- Termostato circular com modos Frio, Automático e Calor
- Controle de portas, garagem e janelas (trancar e destrancar)
- Eletrodomésticos com liga/desliga e status
- Assistente Lume que entende comandos de texto
- Layout responsivo para computador, tablet e celular
